# Chatbot สำนักงาน ก.พ.ร. (OPDC Chatbot)

ระบบตอบคำถามอัตโนมัติสำหรับ สำนักงาน คณะกรรมการพัฒนาระบบราชการ (ก.พ.ร.)
รองรับการถามตอบภาษาไทยและภาษาอังกฤษ โดยดึงคำตอบจากฐานความรู้ของ ก.พ.ร. พร้อมแนบลิงก์แหล่งอ้างอิงทุกครั้ง

---

**สิ่งที่ต้องทำต่อ (ตามลำดับความเร่งด่วน)**

1. แก้ระบบตอบรหัสผิดพลาด 400/413 ให้กลายเป็น 500 (ดู [รายงานหัวข้อ 13](PHASE-D-REPORT.md))
2. เปิดใช้งานการตรวจสอบการอ้างอิงแหล่งข้อมูลในเส้นทางให้บริการจริง และแก้จุดที่ทำให้ตรวจจับปัญหาไม่ได้
3. แก้ระบบจำแนกความต้องการของผู้ใช้ที่ทำงานผิด 4 จาก 21 คำถาม

5. แก้คำสั่ง `npm test` ให้ใช้งานได้จริง

## การติดตั้งและใช้งาน

### ต้องมีอะไรบ้าง

- Node.js เวอร์ชัน 18 ขึ้นไป (ทดสอบแล้วกับ v24.20.0)
- npm

### ติดตั้ง

```bash
cd backend
npm install
```

### เปิดใช้งาน

```bash
cd backend
npm start          # หรือ npm run dev (เปิดใหม่เมื่อแก้โค้ด)
```

เซิร์ฟเวอร์จะฟังที่พอร์ต 8001 เปลี่ยนพอร์ตได้ด้วย `PORT=8100 npm start`

### ทดสอบ

```bash
cd backend
node test/intentClassifier.test.js
node test/security.test.js
# ... ทีละไฟล์
```

> คำสั่ง `npm test` ยังใช้ไม่ได้ (อยู่ในรายการงานที่ต้องแก้) — ใช้เรียกไฟล์ทดสอบทีละไฟล์ไปก่อน

## จุดต่อเชื่อมต่อ (API)

ทั้งหมด 6 จุด อยู่ที่ `backend/server.js`

| วิธีเรียก | ที่อยู่ | ทำอะไร |
|---|---|---|
| GET | `/` | ข้อมูลบริการ |
| GET | `/health` | สถานะระบบ / จำนวนชิ้นข้อมูล / เวลาที่ทำงาน |
| GET | `/v1/intents` | รายการความต้องการ 14 ประเภท |
| GET | `/v1/sources` | รายการแหล่งข้อมูลทั้งหมด |
| POST | `/v1/chat` | ถามคำถาม ได้คำตอบพร้อมแหล่งอ้างอิง |
| DELETE | `/v1/session/:id` | ล้างประวัติบทสนทนา |

### ตัวอย่างการถาม

```bash
curl -X POST http://localhost:8001/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"ก.พ.ร. คืออะไร"}'
```

**ผลลัพธ์**

```json
{
  "answer": "สำนักงาน คณะกรรมการพัฒนาระบบราชการ (ก.พ.ร.) คือ ...",
  "intent": "ORGANIZATION_INFORMATION",
  "sources": ["org_name"],
  "session_id": "a1b2c3d4",
  "citations": [
    { "title": "...", "url": "https://www.opdc.go.th/" }
  ],
  "insufficient_evidence": false
}
```

| ฟิลด์ | ความหมาย |
|---|---|
| `answer` | คำตอบ |
| `intent` | ประเภทความต้องการที่ระบบจำแนกได้ |
| `sources` | รหัสชิ้นข้อมูลที่ใช้ตอบ |
| `session_id` | รหัสบทสนทนา (ส่งกลับมาในคำถามถัดไปเพื่อให้จำบทสนทนาได้) |
| `citations` | รายการอ้างอิงแหล่งข้อมูล |
| `insufficient_evidence` | `true` เมื่อข้อมูลในฐานไม่พอจะตอบ |

## วิธีการทำงาน

```
คำถามผู้ใช้
   ↓
จำแนกความต้องการ (intentClassifier) ── 14 ประเภท
   ↓
ค้นข้อมูลจากฐานความรู้ (rag) ── นับคำที่ตรงกันเป็นข้อความต่อกัน
   ↓
สร้างบริบท + รายการอ้างอิง (contextBuilder)
   ↓
ประกอบข้อความคำสั่ง (promptEngine, promptTemplates)
   ↓
ตรวจสอบคำตอบ + การอ้างอิง (answerValidator, citationValidator)
   ↓
คำตอบพร้อมลิงก์แหล่งอ้างอิง
```

### ข้อควรทราบ

- **ยังไม่ได้เชื่อมต่อโมเดลภาษาใด ๆ** ทุกคำตอบมาจากการประกอบข้อความจากฐานความรู้โดยตรง
- **ระบบค้นข้อมูลด้วยการนับคำที่ตรงกันเป็นข้อความต่อกัน** ไม่ได้ใช้เวกเตอร์หรือระบบความหมาย (ยังไม่มี embedding)
- **บทสนทนาเก็บในหน่วยความจำของเครื่องเท่านั้น** ไม่มีการบันทึกลงฐานข้อมูล และลบทิ้งเมื่อเซิร์ฟเวอร์ปิด สอดคล้องกับ พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล
- **ข้อมูลหลักฐานถูกวางในข้อความระบบ** พร้อมเครื่องหมายคั่น `<source>` และคำเตือนว่าไม่ควรเชื่อถือ เพื่อกันการฉีดคำสั่งจากเอกสาร

## ฐานความรู้

`knowledge/opdc-knowledge.json` แบ่งเป็น 20 ชิ้น ครอบคลุม

- ชื่อหน่วยงานและข้อมูลติดต่อ
- วิสัยทัศน์และภารกิจ
- ประเด็นยุทธศาสตร์ 5 ด้าน
- คณะกรรมการ 5 คณะ
- บริการ 4 บริการ
- ศูนย์ความรู้
- ข้อความทักทาย

## ใบอนุญาตและการใช้งาน

โค้ดนี้จัดทำขึ้นเพื่อสนับสนุนการให้บริการข้อมูลของ สำนักงาน ก.พ.ร.
ก่อนนำขึ้นใช้งานจริง ต้องปิดประเด็นที่ยังไม่ผ่านการทดสอบตามรายงาน และตรวจสอบความถูกต้องของข้อมูลในฐานความรู้กับหน่วยงานต้นทาง
