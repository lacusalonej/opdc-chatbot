# OPDC Chatbot

ระบบแชทบอทสำหรับสำนักงานคณะกรรมการพัฒนาระบบราชการ (ก.พ.ร. / OPDC) แบบใช้กฎ (rule-based) โดยไม่พึ่งพาโมเดล AI หรือ LLM

## คุณสมบัติ

- รันเซิร์ฟเวอร์บนพอร์ต 8001 ด้วย Express.js
- จัดการคำถามแบบ keyword-based RAG (ไม่ต้องใช้ AI)
- จัดเก็บข้อมูลในหน่วยความจำ (RAM เท่านั้น — สอดคล้องกับ PDPA)
- หน้าแชท UI สีขาวสะอาด ใช้งานผ่านเบราว์เซอร์
- เปิดเบราว์เซอร์อัตโนมัติเมื่อเริ่มเซิร์ฟเวอร์
- รองรับภาษาไทยและอังกฤษ

## เริ่มใช้งาน (เริ่มต้นจากศูนย์)

### วิธีรัน (แนะนำ)

double-click ไฟล์ `start-chatbot.bat` แล้วรอให้เซิร์ฟเวอร์เริ่มทำงาน ระบบจะ:

1. ตรวจสอบไฟล์ `backend\server.js`
2. ปิดโปรเซสเก่าที่ใช้พอร์ต 8001 (ถ้ามี)
3. เริ่มเซิร์ฟเวอร์ (`cd backend && node server.js`)
4. รอจนกว่า `/health` จะตอบกลับ (สูงสุด 30 วินาที)
5. เปิดเบราว์เซอร์ที่ `http://localhost:8001`

เซิร์ฟเวอร์จะทำงานต่อในหน้าต่างคอนสโซลแยก คุณสามารถปิดหน้าต่างランチャได้โดยไม่กระทบเซิร์ฟเวอร์

### วิธีรันด้วยตนเอง

```bash
cd backend
npm install
node server.js
```

แล้วเปิดเบราว์เซอร์ที่ `http://localhost:8001`

## เพิ่มข้อมูลให้แชทบอท

แก้ไขไฟล์ `knowledge/opdc-knowledge.json` เพื่อเพิ่มหรือแก้ไขข้อมูลที่แชทบอทใช้ตอบคำถาม โครงสร้างหลักมีดังนี้:

```json
{
  "organization": { ... },      // ข้อมูลองค์กร (ชื่อ, ที่อยู่, โทร, อีเมล ฯลฯ)
  "vision": { ... },            // วิสัยทัศน์
  "mission": { ... },           // ภารกิจ
  "strategic_issues": [ ... ],  // ประเด็นยุทธศาสตร์
  "committees": [ ... ],        // คณะกรรมการ
  "services": [ ... ],          // บริการ
  "events": [ ... ],            // กิจกรรม
  "quick_links": [ ... ],       // ลิงก์ด่วน
  "channels": [ ... ]           // ช่องทางการติดต่อ
}
```

หลังจากแก้ไขไฟล์ JSON ให้รีสตาร์ทเซิร์ฟเวอร์เพื่อให้ข้อมูลใหม่ถูกโหลดเข้าไปใน RAG engine

## โครงสร้างโปรเจกต์

```
opdc-chatbot/
├── chat-test.html              # หน้าแชทหลัก (UI สีขาวสะอาด)
├── start-chatbot.bat           # สคริปต์เริ่มต้นเซิร์ฟเวอร์และเปิดเบราว์เซอร์
├── start-chatbot.ps1.txt       # เวอร์ชัน PowerShell (สำรอง)
├── README.md                   # ไฟล์นี้
├── .gitignore                  # รายการไฟล์ที่ไม่ต้องเก็บใน Git
├── knowledge/
│   └── opdc-knowledge.json     # ฐานความรู้ที่แชทบอทใช้
├── backend/
│   ├── server.js               # Express API (พอร์ต 8001)
│   ├── rag.js                  # RAG engine (ค้นหาและจัดการ chunks)
│   ├── intentClassifier.js     # จำแนก intent จากคำสำคัญ
│   ├── promptTemplates.js      # เทมเพลตคำสั่งตอบตาม intent
│   ├── fallbackResponses.js    # ข้อความตอบกลับเมื่อไม่พบข้อมูล
│   ├── promptEngine.js         # ประมวลผลคำตอบโดยไม่ใช้ LLM
│   ├── contextBuilder.js       # สร้างบริบทจากเอกสารที่ค้นพบ
│   ├── citationValidator.js    # ตรวจสอบการอ้างอิงแหล่งที่มา
│   ├── answerValidator.js      # ตรวจสอบความถูกต้องของคำตอบ
│   ├── package.json            # Dependencies (express, cors, body-parser)
│   └── test/                   # โฟลเดอร์ทดสอบ
└── frontend/
    └── chat-widget.js          # วิดเจ็ตแชทสำหรับฝังในเว็บอื่น (ยังไม่ได้ใช้งานหลัก)
```

## API Endpoints

| Method | Path | คำอธิบาย |
|--------|------|----------|
| GET | `/` | หน้าแชทหลัก |
| GET | `/health` | ตรวจสอบสถานะเซิร์ฟเวอร์ |
| GET | `/v1/intents` | รายการ intent ที่ระบบรองรับ |
| GET | `/v1/sources` | รายการแหล่งข้อมูลในฐานความรู้ |
| POST | `/v1/chat` | ส่งคำถามและรับคำตอบ |
| DELETE | `/v1/session/:id` | ลบเซสชัน (PDPA) |

ตัวอย่างการเรียก `/v1/chat`:

```json
POST http://localhost:8001/v1/chat
Content-Type: application/json

{
  "message": "ก.พ.ร. คืออะไร",
  "session_id": "optional-session-id"
}
```

## หมายเหตุ

- ระบบนี้เป็นแบบ rule-based (คีย์เวิร์ด) ไม่ใช่ AI/LLM ดังนั้นไม่สามารถเรียนรู้หรือปรับปรุงตัวเองได้อัตโนมัติ
- ข้อมูลทั้งหมดถูกจัดเก็บในหน่วยความจำ (RAM) เท่านั้น จะหายเมื่อเซิร์ฟเวอร์หยุดทำงาน สอดคล้องกับ PDPA
- หากต้องการเพิ่มข้อมูลใหม่ ให้แก้ไขไฟล์ `knowledge/opdc-knowledge.json` แล้วรีสตาร์ทเซิร์ฟเวอร์
