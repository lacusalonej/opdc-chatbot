ระบบแชทบอทสำหรับสำนักงานปลัดกระทรวงการคลัง (สปก.)

Rule-based · ไม่พึ่ง LLM · สอดคล้อง PDPA

เกี่ยวกับระบบ

MOF Chatbot คือระบบแชทบอทแบบใช้กฎ (rule-based) ที่พัฒนาขึ้นเพื่อตอบคำถามจากประชาชนเกี่ยวกับภารกิจและบริการของสำนักงานปลัดกระทรวงการคลัง (สปก.) โดยไม่ต้องพึ่งพาโมเดล AI หรือ LLM ภายนอก ทำให้มั่นใจในเรื่องความปลอดภัยของข้อมูลและสอดคล้องกับพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล (PDPA)

คุณสมบัติหลัก

ตอบคำถามแบบ keyword-based

ค้นหาคำตอบจากฐานความรู้ที่จัดเก็บไว้ในไฟล์ JSON โดยใช้การจับคู่คำสำคัญ

รองรับภาษาไทยเต็มรูปแบบ

ออกแบบมาให้รองรับภาษาไทยเป็นหลัก ใช้งานได้ง่ายสำหรับประชาชนทั่วไป

เก็บข้อมูลใน RAM เท่านั้น

ข้อมูลการสนทนาถูกจัดเก็บในหน่วยความจำเท่านั้น ลบเมื่อจบเซสชัน สอดคล้อง PDPA

หน้าแชทใช้งานง่าย

UI สีขาวสะอาด รองรับการแสดงผลบนมือถือและเดสก์ท็อป

ระบบแอดมิน

จัดการฐานความรู้ ผู้ใช้ สนทนา และการตั้งค่าระบบผ่านหน้าแอดมิน

ทดสอบอัตโนมัติ

มีชุดทดสอบครอบคลุมทั้งการจำแนก intent, RAG, คำตอบ และความปลอดภัย

วิธีเริ่มใช้งาน

ขั้นตอนการติดตั้ง

1. ติดตั้ง dependencies:
cd backend && npm install

2. เริ่มเซิร์ฟเวอร์:
node server.js

3. หรือใช้สคริปต์เริ่มต้น:
start-chatbot.bat (Windows)

4. เปิดเบราว์เซอร์ที่: http://localhost:8001

API Endpoints หลัก

  • GET /health — ตรวจสอบสถานะเซิร์ฟเวอร์
  • GET /v1/intents — รายการ intent ที่ระบบรองรับ
  • GET /v1/sources — รายการแหล่งข้อมูลในฐานความรู้
  • POST /v1/chat — ส่งคำถามและรับคำตอบจากแชทบอท
  • DELETE /v1/session/:id — ลบข้อมูลเซสชัน (PDPA)
